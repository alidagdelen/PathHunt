# PathHunt

A lightweight, command-line utility built in Python designed for keyword searches within files and modular File Integrity Monitoring (FIM). 

## Features

- **Keyword Search Engine:** Quickly scan directories for specific keywords within targeted file extensions.
- **Interactive Terminal Menu:** Clean, color-coded CLI navigation.
- **File Integrity Monitoring (FIM):** Built-in structure for system and directory tracking (modular architecture).
- **Error Handling:** Graceful interrupt handling (`KeyboardInterrupt`) and path validation checks.

## Requirements

- Python 3.x
